# 손 모델 3D (Hand Model 3D) 사용법

> 실행 파일: `HandModel3D\build\HandModel3D.exe` (빌드: `HandModel3D\build.bat`)
> — 프로그램 이름은 '손 모델 3D'지만 **실행 파일 이름은 `HandModel3D.exe`** 다(`손모델3D.exe` 아님).
> 목적: 타이핑하는 손 모양을 3D로 만들어 **2D 윤곽선**을 뽑고, 그것을 OpenTypingPlus(이하 OTP)
> '키보드 연습 창'의 손가락 레이어 그림으로 쓴다.
> 관련 문서: [physical-key-master.md](physical-key-master.md)(물리 키 ↔ 담당 손·손가락)

---

## 1. 화면 구성

### 1-1. 제목 표시줄

`열기` · `저장` · `설정` · `도움말` · `정보`. 제목에는 지금 열려 있는 파일 이름이 함께 나온다.

**도움말**을 누르면 지금 보고 있는 이 사용법 문서가 새 창으로 열린다. 문서는 실행 파일 안에 들어 있어서
따로 파일을 들고 다닐 필요가 없고, 그 창의 **출력** 버튼을 누르면 어디에 저장할지 물은 뒤
원본 마크다운(`손모델3D_사용법.md`) 그대로 꺼내 준다.

### 1-2. 상단 패널 (왼쪽 → 오른쪽)

| 패널 | 내용 |
|---|---|
| **크기** | 양손 전체 배율. 아래 숫자를 클릭하면 키보드로 직접 입력할 수 있다. |
| **좌우** | 상하 길이 대비 좌우 길이의 비율(손을 넓적하게/갸름하게). |
| **손가락 길이** | 소지·약지·중지·검지·엄지의 길이 배율(양손 대칭). |
| **볼륨** | 살(근육·지방)의 두께. |
| **투명도** | 0%(불투명)~100%(완전 투명). 위·아래의 `0%`·`100%` 버튼으로 한 번에. |
| **피부색** | 프리셋 6종 + `색 상세…`(RGB/HSL 창). |
| **윤곽선** | `보이기`/`윤곽선만`, 두께, 색 프리셋, `모드: 가림↔항상`, `손끝 색…`. |
| **손 회전** | 손별로 세로축·가로축·수직축(도). `0°` 버튼으로 초기화. |
| **손 위치** | 공통·왼손·오른손의 X/Y/Z. `0` 버튼으로 초기화. |
| **카메라(캡처)** | 캡처 대상(둘 다/왼손만/오른손만), `비트맵 캡처(PNG)`, `벡터 캡처(SVG)`, `벡터 내부 채움`. |
| **배경 키보드** | 없음 / 두벌식 표준 / QWERTY. |
| **배경 이미지** | 참고 그림 열기·지우기. |
| **빨간 고정점** | 고정점 표시의 투명도. |

### 1-3. 좌우 관절 패널

`왼손 관절` · `오른손 관절` 패널에 관절 슬라이더가 손 모양대로 배치된다.
각 패널 위쪽 버튼 세 개:

- **표시** — 그래픽 영역에 관절 이름표를 켜고 끈다.
- **크기** — 이름표 글자 크기.
- **초기화** — **그 손의** 모든 관절을 초기값으로 되돌린다(반대 손은 그대로).

슬라이더 값은 모두 **0~100%** 이고, 100%가 최대로 펴고 벌린 상태다. 숫자를 클릭하면 직접 입력할 수 있다.

### 1-4. 그래픽 영역 위의 작은 패널

왼쪽 아래에 **시점 회전**(x/y/z와 `0` 버튼), 그 오른쪽에 **물갈퀴 살**(손가락 사이 살의 높이),
**살 반응**(손가락을 모으면 살이 부풀고 벌리면 얇아지는 정도).

### 1-5. 상태 표시줄

조작 안내와 결과(저장 경로 등)가 나온다. **문구가 늘어 두꺼워져도 손과 배경 키보드는 움직이지 않는다.**

## 2. 마우스·키보드 조작

| 조작 | 결과 |
|---|---|
| 배경(손 밖) 드래그 | 시점 회전 |
| 왼쪽 아래 xyz 기즈모 드래그 | 시점 회전 |
| 오른쪽 버튼 드래그 · `[Shift]`+드래그 | 화면 이동(팬) |
| 휠 | 줌 |
| 손 위에서 **클릭** | 그 관절에 **빨간 고정점** 켜기/끄기 |
| 손 위에서 **드래그** | IK — 끌린 손끝을 따라 그 손가락이 굽는다 |
| **`[Ctrl]`+한 손 드래그** | 그 손만 위치 이동 |
| **`[Ctrl]`+드래그**(손 밖) | 배경 키보드·배경 이미지 확대/축소 |
| **`[Ctrl]`+클릭**(배경 키보드 위) | 그 키를 **눌린 키(진한 노란색)** 로 토글. 모든 키가 대상이고, 두 [Shift]는 따로따로, 그 밖의 키는 한 번에 하나만 |
| 방향키 | 양손을 함께 이동 |
| `[Ctrl]`+`[Z]` / `[Ctrl]`+`[Y]` | 실행 취소 / 다시 실행 |

> 배경 키보드를 띄우면 `[Ctrl]`을 눌러야 키보드를 조작할 수 있다(안 누르면 순수 배경).
> 손가락이 그래픽 영역 밖으로 나가는 조작은 거부되고 빨간 문구가 뜬다.

## 3. 파일

### 3-1. 열기 / 저장

- **열기** — 저장해 둔 `.json`을 불러온다. 관절·크기·시점·배경 키보드·고정점까지 그대로 재현된다.
- **끌어다 놓기** — json 파일을 창에 떨어뜨려도 열린다. **손 모델 정보가 들어 있는 파일만** 열리고,
  아니면 "손 모양 정보가 없는 JSON 파일입니다"라고 알린다.
- **저장** — 연 파일과 **달라진 것이 없으면** 저장 창을 띄우지 않고 "달라진 것이 없습니다."만 보여 준다.
  달라졌으면 그 파일의 폴더·이름이 선택된 채로 저장 창이 뜬다. 그대로 저장하면 덮어쓰기,
  이름을 고치면 다른 이름으로 저장.

### 3-2. 설정 창

- **비트맵 캡처 파일(PNG) 위치** / **벡터 캡처 파일(SVG) 위치** / **저장 파일(json) 위치** — 따로 지정.
- 캡처 두 종류에는 **파일 이름: 자동 / 캡처 시 파일 이름 수동 입력** 선택이 있다.
  수동이면 캡처할 때 저장 창이 뜨고(자동 이름이 미리 채워짐), **지정한 파일 하나만** 저장된다.
- **초기값** — 크기·좌우·물갈퀴 살·양손 X/Y·두 엄지 좌우 CMC. 고치면 **바로 반영되고 다음 실행에도 적용**된다.
  `저장…`/`불러오기…`로 `초기값_*.json` 파일에 담아 둘 수 있다(손 모양 파일과는 별개).

## 4. 캡처

### 4-1. 비트맵 캡처(PNG)

화면의 3D 손과 **배경 키보드**를 합쳐 PNG로 저장한다. 관절 이름표·좌표축·경고 문구 같은 겉표시는
들어가지 않지만, **켜 둔 빨간 고정점은 예외로 함께 그려진다.**

자동 이름은 `[키라벨]_시각.png`이고, 배경 키보드에서 키를 눌러 두었으면 `[행-열]_[키라벨]_시각.png`도
함께 만들어진다.

### 4-2. 벡터 캡처(SVG)

윤곽선을 **선(벡터)** 으로 저장한다. 화면·비트맵과 **같은 판정으로 만든 최종 윤곽선을 그대로** 따므로,
바깥 실루엣뿐 아니라 **손가락끼리 맞닿은 선, 살 속에 갇힌 폐곡선까지** 같이 들어간다.
선 색·두께도 '윤곽선' 패널 설정을 따른다.

- **배경 키보드를 켜 두면** 좌표가 OTP 키보드와 같은 **777×260 단위**로 나온다 → OTP에 그대로 이식 가능.
- **꺼 두면** 화면 픽셀 좌표로 나오고, 그 사실을 그래픽 영역에 알려 준다.
- `벡터 내부 채움`은 확인용이다. OTP는 선만 쓰므로 꺼 두는 것이 기본.
- 만들어진 SVG를 **다른 프로그램에서 다시 저장하면** OTP에 쓸 정보가 지워질 수 있다.

## 5. OTP 손가락 레이어로 넘기는 방법

1. 손 모양을 만들고 **배경 키보드를 켠 채로** `저장`해 `HandModel3D\sample-json\`에 모은다.
   파일 이름의 `[ㄹ]`, `기본자세` 같은 표시로 어느 키의 손 모양인지 구분한다.
2. 한 키에 캡처가 여러 개면 쓸 것을 `HandModel3D\tools\확정본.txt`에 적는다(적지 않은 키는 자동 선택).
3. 다음을 실행하면 추출부터 OTP 배포까지 한 번에 끝난다.

```bash
powershell -ExecutionPolicy Bypass -File D:\myclaude\claud6_typing_Csharp\HandModel3D\tools\update-hands.ps1
```

| 단계 | 하는 일 |
|---|---|
| ① 추출 | `-svgexportall`로 sample-json 전체를 SVG로 |
| ② 선택 | `확정본.txt` 우선, 나머지는 자동(기본 라벨 우선) |
| ③ 검증 | 담당 손가락이 그 키를 짚는지 좌표로 확인 — **실패하면 설치하지 않고 멈춘다** |
| ④ 설치 | `OpenTyping\hands\`에 `{행}-{열}-{손}.svg`, `home-*`, `lshift/rshift` |
| ⑤ 배포 | OTP 빌드 + `build.bat` |
| ⑥ 배선 확인 | OTP가 키마다 **실제로 읽은 파일 이름**을 기대와 대조 |

자주 쓰는 스위치: `-WriteList`(확정본 목록만 생성) · `-SkipExport`(다시 뽑지 않고 설치만) ·
`-NoDeploy` · `-Force`(검증 실패 무시).

> OTP는 손 그림이 없으면 예전 방식(ContourHand)으로 자동 폴백하므로, 일부만 갖춰져 있어도 안전하다.

### 5-1. 단계마다 필요한 것 / 없을 때

`HandModel3D.exe` 하나만으로는 돌지 않는다. exe는 ①에서 재료(SVG)를 만드는 도구일 뿐이고,
나머지 단계가 실제로 다루는 재료는 마스터 표·`sample-json`·`svg-out`·OTP 소스 트리다.

| 단계 | 필요한 것 | 없으면 |
|---|---|---|
| (시작 전) | `HandModel3D\physical-key-master.json` | **必**. 없으면 ①에 닿기도 전에 멈춘다 |
| ① 추출 | `HandModel3D\build\HandModel3D.exe`, 포즈 json 폴더 | "손 모델 3D 실행 파일이 없습니다" |
| ② 선택 | (선택) `tools\확정본.txt` | 없어도 됨 — 전부 자동 선택 |
| ③ 검증 | `svg-out\_export.log` (①이 남긴다) | "추출 로그가 없습니다" |
| ④ 설치 | `OpenTyping\hands\` | 폴더는 자동으로 만든다 |
| ⑤ 배포 | dotnet SDK, OTP 소스, `OpenTypingPlus\build.bat` | 빌드·배포 실패로 중단 |
| ⑥ 배선 | 배포된 `OpenTypingPlus\build\OpenTypingPlus.exe` | **조용히 건너뛴다**(오류 아님) |

경로는 전부 바꿀 수 있다: `-Poses`(포즈 json) · `-SvgOut` · `-Hands`(설치 대상) · `-List` · `-Exe`.

단계를 잘라 쓰는 경우:

- OTP 쪽이 없거나 건드리고 싶지 않다 → `-NoDeploy` (④ 설치까지)
- exe가 없다 → `-SkipExport`. 단, ③이 로그를 보므로 **`svg-out`을 `_export.log`째로** 가지고 있어야 한다.
- 확정본 목록만 만들어 본다 → `-WriteList`. `sample-json`과 마스터 표만 있으면 **exe 없이도** 된다.

> ⚠️ 앱 소스를 고쳤으면 `HandModel3D\build.bat`으로 **다시 배포한 뒤** 스크립트를 돌린다.
> 배포본이 옛 빌드면 ①이 모르는 스위치를 받아 아무 일도 하지 않은 채 멈춘 것처럼 보인다(실제로 겪은 함정).

## 6. 개발·검증용 커맨드라인 (일반 사용에는 필요 없음)

### 6-1. 산출·재현

| 스위치 | 뜻 |
|---|---|
| `-poseshot <상태json> <출력png>` | 상태를 불러와 창 스냅샷 한 장을 찍고 종료 |
| `-svgexport <상태json> <왼svg> <오른svg>` | 한 파일을 양손 SVG로 |
| `-svgexportall <입력폴더> <출력폴더>` | 폴더 전체를 한 번에(로그에 손끝 좌표 포함) |
| `-shot` / `-settingsshot` | 메인 창 / 설정 창 스냅샷 |
| `-outlineonly`, `-alwaysmode`, `-labels`, `-kbtest`, `-bgtest` 등 | 시작 상태를 바꿔 띄운다 |

### 6-2. 자가 검증(회귀 배터리)

`-savetest`(저장/열기 왕복) · `-undotest` · `-iktest` · `-edgecap` · `-capsvg` · `-statusbartest` ·
`-dirtest` · `-droptest` · `-savereset` · `-defaultstest` · `-pincaptest` · `-kbtoggle` · `-vectest` ·
`-helptest`(도움말 창: 단추 순서·문서 읽기·렌더 개수·'출력' 왕복. 창 그림은 `%LOCALAPPDATA%\3dm_help.png`)

결과는 `%LOCALAPPDATA%\3dm_qa.txt`에 남는다. **소스를 고쳤으면 이 배터리를 모두 통과시킨 뒤 배포한다.**

### 6-3. 잠복 진단(환경 변수, 켜지 않으면 아무 영향 없음)

| 변수 | 하는 일 |
|---|---|
| `HM3D_TAGDUMP` | 손가락별 색으로 칠한 태그 그림을 함께 저장 |
| `HM3D_COLDUMP` | 충돌 판정 수치 덤프 |
| `HM3D_PINZONE` | '눌림 영역' 판정 덤프 |
| `HM3D_BMPCAP` | `-poseshot` 때 비트맵 캡처도 실행(`=2`면 확장 캡처까지) |
| `HM3D_SVGCAP` | `-poseshot` 때 같은 렌더의 SVG를 캔버스 좌표로 저장(비트맵과 픽셀 대조용) |

## 7. 알아 두면 좋은 규칙

- **좌표 정합의 기준은 배경 키보드다.** 배경 키보드는 OTP 원본 자판과 치수가 똑같이 맞춰져 있어서
  (키 50×50, 간격 2, 행 피치 52, 전체 777×260), 화면에서 손가락이 짚은 키가 OTP에서도 그대로 그 키다.
- **그래서 배경 키보드의 확대율을 바꾸면 손과 키의 관계가 실제로 바뀐다.** 손 크기와 키보드 크기를
  함께 맞춰 둔 상태(예: `기본자세_확정`)를 기준으로 작업하는 것이 안전하다.
- 손목 아래쪽은 화면 바닥에서 잘린다. OTP 연습 창에서도 같은 방식으로 잘린다.
- 배경 키보드의 `⧵`(역슬래시) 키는 담당 손가락이 정해져 있지 않아 손 모양을 만들지 않는다(연습 제외 키).
- `HandModel3D` 폴더는 git 저장소가 아니다. 되돌릴 안전망이 없으니 파일을 지우거나 덮어쓸 때 주의한다.
